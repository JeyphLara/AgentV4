# AGENTV4

AGENTV4 es mi proyecto personal de sistemas inteligentes, diseñado para integrar control de dispositivos, procesamiento de información y comportamientos guiados por IA.

## Visión del proyecto

AGENTV4 funciona como una plataforma de agentes autónomos: conecta hardware, APIs y scripts de automatización en un flujo inteligente capaz de interactuar con un entorno real.

El proyecto explora:
- control remoto de dispositivos Android TV
- análisis y manipulación de imágenes
- automatización de tareas y procesos
- integración con sistemas inteligentes y asistentes virtuales

## Capacidades principales

### Control de Android TV

`controltv.py` es el componente que permite sincronizar con una TV Android, emparejarla y ejecutar comandos remotos. Esto convierte al proyecto en un agente capaz de controlar un dispositivo físico desde Python.

### Automatización inteligente

Los distintos scripts del proyecto muestran un enfoque pragmático para crear sistemas que reaccionan a entradas externas, toman decisiones simples y ejecutan acciones automáticas.

### Procesamiento de imágenes

El proyecto incluye módulos orientados a manejar imágenes desde la lógica de un agente: detección, edición y generación son piezas importantes de AGENTV4.

## Arquitectura

AGENTV4 agrupa código en capas:
- scripts principales que ejecutan acciones específicas
- configuración centralizada para dispositivos y servicios
- lógica de control y comunicación

El diseño permite ampliar el proyecto con nuevos agentes, nuevas fuentes de datos y nuevos actuadores.

## Componentes clave

- `controltv.py`: gestor de emparejamiento y comandos remotos para Android TV
- `aurora.py`: parte de la lógica principal del asistente
- `imgescript.py` / `newimage.py`: procesamiento y manipulación de imágenes
- `script.py`: lógica genérica de automatización
- `config/devices.json`: definición de dispositivos y conexiones

## Inteligencia y comportamiento

AGENTV4 está pensado como un núcleo que puede evolucionar hacia:
- asistentes inteligentes que controlan hardware
- sistemas de respuesta automática
- orquestadores de acciones basados en datos y contexto

No es solo un conjunto de scripts; es una base para integrar IA con dispositivos físicos y servicios.
